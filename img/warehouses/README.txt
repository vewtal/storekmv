ФОТО СКЛАДОВ — как добавить
============================

Положите сюда фотографии корпусов с ТОЧНО такими именами файлов.
Карточка на странице каталога (pages/warehouses.html) подхватит фото
автоматически. Если файла нет — останется аккуратный градиент-плейсхолдер
(ничего не сломается).

Имя файла → объект:
  155-9.jpg    → Склад 155/9
  lit-p.jpg    → Склад 155 Лит.П
  155-6-a.jpg  → Склад 155/6 Лит.А
  155-6-b.jpg  → Склад 155/6 Лит.Б
  155-4-b.jpg  → Склад 155/4 Лит.Б
  155-4-v.jpg  → Склад 155/4 Лит.В
  p2.jpg       → Склад П2 (охлаждаемый)

Требования к фото:
  - формат: JPG
  - ориентация: горизонтальная (landscape)
  - соотношение сторон близко к 16:10
  - ширина 1200–1600 px (не больше — чтобы страница не тормозила)
  - вес желательно до ~300 КБ на файл

После добавления файлов сообщите — я продублирую те же фото
в карточки на главной странице (секция «Каталог объектов»).
